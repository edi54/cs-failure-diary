# [BOJ 20044] Project Teams — Greedy 오답노트

## 1. 문제 개요

- 문제 번호: BOJ 20044
- 문제명: Project Teams
- 조건: 학생 수 = 2N (N ≤ 문제 조건 내)
- 목표: 2명씩 팀을 구성했을 때 **모든 팀 중 최대 팀 실력의 최솟값** 계산

## 2. 최초 오답 접근 요약

- 학생 실력을 오름차순 정렬
- 가장 작은 값과 가장 큰 값을 매칭하는 Greedy 전략 사용
- 각 팀의 실력을 계산하며 **최소값을 추적**

## 3. 오답 원인 분석

### (1) 최적화 대상 오해

- 문제의 요구사항은  
  **팀 실력 중 최대값을 최소화하는 것**
- 최초 접근에서는  
  팀 실력 중 **최소값**이 의미 있는 지표라고 잘못 판단함
- 결과적으로 문제에서 요구하는 값과  
  **정반대의 지표를 계산**함

### (2) Minimize-the-Maximum 유형 인식 실패

- 이 문제는 개별 팀의 우수성을 비교하는 문제가 아니라
- **가장 나쁜 경우(Worst Case)를 얼마나 억제할 수 있는지**가 핵심
- Greedy 전략의 목적을  
  “작은 값을 줄이는 것”으로 잘못 해석함

## 4. 정답 접근에서의 핵심 교정 사항

- Greedy 전략 자체(양 끝 매칭)는 유지
- 추적해야 할 지표를 명확히 수정
  - `min(team_sum)` ❌
  - **`max(team_sum)` ⭕️**
- 모든 팀을 동일하게 평가하지 않고
  - **전체 결과를 결정하는 단일 지표(최대 팀 실력)**만 추적

## 5. 정답 코드의 핵심 논리 요약

- 학생 실력을 오름차순 정렬
- 가장 작은 값과 가장 큰 값을 한 팀으로 구성
- 각 팀의 실력을 계산하며
  - 전체 팀 중 **최대 팀 실력**을 갱신
- 최종적으로 해당 최대값 출력

## 6. 재발 방지 체크리스트

- 최적화 대상이 무엇인지 명확히 정의했는가?
  - `min`을 줄이는 문제인지
  - `max`를 억제하는 문제인지
- 문제에서 요구하는 출력값이
  - 전체 중 최소인지 / 최대인지 명확히 확인했는가?
- Greedy 전략이
  - 무엇을 제어하기 위한 전략인지 설명 가능한가?
- 전체 합 / 평균 / 최소값이
  - 실제로 문제 해결에 의미 있는 지표인지 검증했는가?

## 7. 분류 및 태그

- Algorithm: Greedy
- Pattern: Minimize the Maximum
- Key Issue: Optimization target misinterpretation
